# Decisiones

Cada decisión que cueste deshacer queda escrita aquí: qué se decidió, por qué y qué se descartó.
Así, dentro de un año, nadie tiene que adivinar por qué la web es como es.

- Se numeran en orden y no se borran. Si una decisión cambia, se escribe otra nueva que la **sustituye**
  y en la antigua se cambia el estado a "Sustituida por NNNN".
